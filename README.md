📘 LeetLab – MERN Stack Clone (In Development)

This project is a full MERN Stack clone of LeetLab, a coding practice and learning platform.
I am building this project to improve my full-stack development skills, understand large-scale architecture, and create a production-ready application.

🚀 Project Goal

The goal of this project is to recreate the core features of LeetLab using modern MERN technologies:

Practice coding questions

User authentication system

Track progress and submissions

Admin panel (optional)

Clean UI & scalable backend

Real-world project structure

This project is built for learning purposes & portfolio.

🛠 Tech Stack
